Home Server / Homelab

Linux · Docker · Networking · Troubleshooting

Turned an old desktop (Ryzen 5 2600, GTX 1660 Ti) into a 24/7 Ubuntu server that replaces several paid services. It runs a CasaOS-managed Docker stack: Immich for photos, Jellyfin with GPU transcoding, Pi-hole, a Tailscale exit node, Samba, PostgreSQL, a local LLM through Ollama and Open WebUI, Uptime Kuma, Code Server, Audiobookshelf, Kiwix, and Wolf for game streaming.

The interesting part has been fixing what broke: tracing a server crash to thermals from concurrent ML jobs, fighting immich-go through an API version mismatch and NTFS permission walls to migrate family photo archives, moving ML work onto the GPU, and running ethernet to the basement with WiFi kept as failover.
