Automated Calendar Synchronization Pipeline

Role: Automation Architect | Tools: Google Apps Script, JS, Spreadsheet Logic

The Business Problem

Meticulous schedule planning requires centralized visibility. My organization utilizes Synerion for workforce management, but the platform lacks a native integration to export scheduled shifts directly into external calendars like Google Calendar. This disconnect forced a tedious, manual data-entry process to ensure work schedules didn't conflict with personal and academic commitments.

The Data Transformation

To bridge the gap, I designed a multi-step data transformation pipeline. Synerion allows for a CSV export of monthly schedules, but the output formats dates and times as a single, unusable string (e.g., 3/31 - 13:00-21:15).

I utilized Google Sheets as an intermediary translation layer, employing string-parsing formulas to isolate and mathematical functions to convert the raw text into valid DateTime objects:

// Extracting and calculating Start Time
=C23+TIMEVALUE(LEFT(D23,FIND("-",D23)-1))
// Extracting and calculating End Time
=C23+TIMEVALUE(MID(D23,FIND("-",D23)+1,LEN(D23)))

The Apps Script Automation

With the data cleanly formatted, I developed a Google Apps Script bound to the spreadsheet. The script iterates through the parsed data, performs type-checking validation, interacts with the Google Calendar API to generate events, and features error-handling and duplicate-prevention logic.

/**
 * Creates Google Calendar events from a spreadsheet schedule.
 * Includes status checks to prevent duplicate event creation.
 */
function createWorkSchedule() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getActiveSheet();
  const values = sheet.getDataRange().getValues();
  const calendar = CalendarApp.getDefaultCalendar();
  
  // Loop through rows, skipping header
  for (let i = 1; i < values.length; i++) {
    const row = values[i];
    const startTime = row[0]; 
    const endTime = row[1];   
    const status = row[2];    
    
    // Duplicate prevention
    if (status === "Added") continue; 
    
    // Type checking and validation
    if (!startTime || !endTime || !(startTime instanceof Date)) continue; 

    try {
      const event = calendar.createEvent("Work", startTime, endTime);
      event.addPopupReminder(60);
      
      // Write success status back to spreadsheet
      sheet.getRange(i + 1, 3).setValue("Added");
      
    } catch (e) {
      Logger.log(`Failed to create event for row ${i + 1}: ${e}`);
    }
  }
}

Impact & Takeaways

This pipeline completely eliminated manual scheduling processes. By transforming raw CSV data into a functional API payload, I engineered a zero-maintenance workflow that ensures 100% accuracy in calendar syncing, protecting my time and ensuring zero overlap with other obligations.
