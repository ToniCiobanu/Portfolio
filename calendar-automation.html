Shift schedule → Google Calendar

My work schedule lives in a system that can't talk to my calendar. A few spreadsheet formulas and a short script fixed that.

TypePersonal project
ToolsGoogle Sheets, Apps Script (JavaScript)
ResultExport, paste, one click

The problem

My work schedule lives in Synerion, which can't send shifts to Google Calendar. Every month I was retyping each shift by hand so work wouldn't clash with everything else in my calendar.

The data transformation

Synerion can export a month of shifts as a CSV, but it crams the date and time range into one string:

3/31 - 13:00-21:15

I paste that into Google Sheets and use string-parsing formulas to split it into real start and end date/time values:

// Start time
=C23+TIMEVALUE(LEFT(D23,FIND("-",D23)-1))

// End time
=C23+TIMEVALUE(MID(D23,FIND("-",D23)+1,LEN(D23)))

The Apps Script automation

A short Apps Script bound to the sheet then walks the rows, skips anything that is not a valid date or was already added, creates a "Work" event with a one-hour reminder, and marks the row as Added so re-running it never creates duplicates.

/**
 * Creates Google Calendar events from a spreadsheet schedule.
 * Includes status checks to prevent duplicate event creation.
 */
function createWorkSchedule() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getActiveSheet();
  const values = sheet.getDataRange().getValues();
  const calendar = CalendarApp.getDefaultCalendar();

  // Loop through rows, skipping header
  for (let i = 1; i < values.length; i++) {
    const row = values[i];
    const startTime = row[0];
    const endTime = row[1];
    const status = row[2];

    // Duplicate prevention
    if (status === "Added") continue;

    // Type checking and validation
    if (!startTime || !endTime || !(startTime instanceof Date)) continue;

    try {
      const event = calendar.createEvent("Work", startTime, endTime);
      event.addPopupReminder(60);
      // Write success status back to spreadsheet
      sheet.getRange(i + 1, 3).setValue("Added");
    } catch (e) {
      Logger.log(`Failed to create event for row ${i + 1}: ${e}`);
    }
  }
}

Result

Retyping a month of shifts by hand is now an export, a paste, and one click. It is a small tool, but it is the kind of thing I like doing: find the annoying manual step and remove it with whatever is already on hand.
