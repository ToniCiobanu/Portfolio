Query 1: Cost Summary by Vehicle

-- Q1: Total DIY vs Mechanic Cost by Vehicle SELECT v.make || ' ' || v.model || ' ' || v.year AS vehicle, v.odometer_km, COUNT(r.item_id) AS num_repairs, ROUND(SUM(r.diy_parts_cost), 2) AS total_diy_cost, ROUND(SUM(r.mechanic_est_total), 2) AS total_mechanic_est, ROUND(SUM(r.savings), 2) AS total_savings, ROUND(SUM(r.savings) / SUM(r.mechanic_est_total) * 100, 2) AS savings_pct FROM vehicles v JOIN repair_line_items r ON v.vehicle_id = r.vehicle_id GROUP BY v.vehicle_id, v.make, v.model, v.year, v.odometer_km ORDER BY total_savings DESC;

Query 2: Savings by Category

-- Q2: Cost breakdown and savings rate by repair category SELECT rc.category_name, COUNT(r.item_id) AS num_repairs, ROUND(SUM(r.diy_parts_cost), 2) AS diy_cost, ROUND(SUM(r.mechanic_est_total), 2) AS mechanic_cost, ROUND(SUM(r.savings), 2) AS total_savings, ROUND(SUM(r.savings) / SUM(r.mechanic_est_total) * 100, 2) AS savings_pct FROM repair_categories rc JOIN repair_line_items r ON rc.category_id = r.category_id GROUP BY rc.category_id, rc.category_name ORDER BY total_savings DESC;

Query 3: Parts Source ROI

-- Q3: Which parts source provided the best ROI? SELECT r.parts_source, COUNT(*) AS items_purchased, ROUND(SUM(r.diy_parts_cost), 2) AS total_spent, ROUND(SUM(r.savings), 2) AS total_savings, ROUND(AVG(r.savings), 2) AS avg_savings_per_item, ROUND(SUM(r.savings) / NULLIF(SUM(r.diy_parts_cost), 0) * 100, 1) AS roi_pct FROM repair_line_items r GROUP BY r.parts_source ORDER BY total_savings DESC;

Query 4: Best & Worst Value Repairs (Window Function)

-- Q4: Rank all repairs by savings % using RANK() window function SELECT v.make || ' ' || v.model AS vehicle, r.description, rc.category_name, r.diy_parts_cost, r.mechanic_est_total, r.savings, r.savings_pct, RANK() OVER (ORDER BY r.savings_pct DESC) AS best_value_rank, RANK() OVER (ORDER BY r.savings_pct ASC) AS worst_value_rank FROM repair_line_items r JOIN vehicles v ON r.vehicle_id = v.vehicle_id JOIN repair_categories rc ON r.category_id = rc.category_id ORDER BY best_value_rank;

Query 5: Cumulative Spend Tracking (CTE + Window)

-- Q5: Cumulative spend by category using CTE and running total WITH category_spend AS ( SELECT rc.category_name, SUM(r.diy_parts_cost) AS cat_diy, SUM(r.mechanic_est_total) AS cat_mechanic, SUM(r.savings) AS cat_savings FROM repair_line_items r JOIN repair_categories rc ON r.category_id = rc.category_id GROUP BY rc.category_name ) SELECT category_name, ROUND(cat_diy, 2) AS diy_spend, ROUND(cat_mechanic, 2) AS mechanic_est, ROUND(cat_savings, 2) AS savings, ROUND(SUM(cat_diy) OVER ( ORDER BY cat_savings DESC ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW ), 2) AS cumulative_diy, ROUND(cat_savings / cat_mechanic * 100, 2) AS savings_pct FROM category_spend ORDER BY savings DESC;

💡 Key Insights & Findings

1. 85.93% Savings Rate Across Both Vehicles

Across 23 repairs, DIY methods saved $10,089.26 (85.93%) vs. verified mechanic/dealership quotes. Both vehicles achieved nearly identical rates — Pontiac 85.50%, Elantra 86.36% — suggesting the savings model is consistent regardless of vehicle age.

2. Junkyard Sourcing = Highest ROI at 1,234%

The two junkyard-sourced items (hood $100, brake light housing $5) generated $1,295.48 in savings — a 1,234% ROI. The hood alone saved $1,242.68 vs. dealership pricing of $1,342.68. For structural non-wear parts, junkyard sourcing is unmatched.

3. Safety Inspection Items: Highest Category Savings Rate (93.51%)

5 safety inspection failure items cost only $192 DIY vs. $2,956.43 at a mechanic — a 93.51% savings rate. The front bumper repair ($30 DIY vs. $1,075.76 mechanic) is the single most striking example of DIY value in this dataset.

4. Best Value: Sway Bar Link (97.4% savings)

A $6.50 sway bar link from RockAuto would cost $250 at a mechanic — a 3,746% ROI and the highest savings percentage in the dataset. Small suspension components like this represent the highest-leverage DIY repairs.

5. Worst Value: Battery Replacement (26.55% savings)

The battery was purchased at retail ($220.34) while the mechanic quote was only $300 — a narrow $79.66 spread. Mechanic markup on batteries is low because they source them at wholesale. Batteries are the weakest case for DIY in this dataset.

6. Electrical & Audio: Lowest Category Savings Rate (55.51%)

Electrical work (speakers + battery) had the lowest savings rate at 55.51%. The BOSE speakers were premium-priced ($224.58) while mechanic audio installs are relatively affordable. Electrical DIY still saves money, but is the least efficient category compared to suspension or safety work.
